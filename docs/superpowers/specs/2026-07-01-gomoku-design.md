# 五子棋人机对战 — 设计规格书

**日期:** 2026-07-01
**状态:** 待审核

## 概述

单文件 HTML 五子棋游戏，玩家执黑先行，对战基于模式评估的启发式 AI。零依赖，浏览器直接打开即可运行。

## 技术栈

- 单个 HTML 文件（内嵌 CSS + JavaScript）
- Canvas API 绘制棋盘和棋子
- 无框架、无构建工具、无外部依赖

## 架构

```
┌──────────────────────────────────┐
│           Game Controller        │
│  (回合流转 / 悔棋 / 重置 / 状态) │
├──────────────────────────────────┤
│  Board State  │  AI Engine       │
│  15×15 数组   │  模式评分 +      │
│  走子历史栈   │  候选筛选        │
├──────────────────────────────────┤
│  Win Detector │  Renderer        │
│  4方向扫描    │  Canvas 绘制     │
└──────────────────────────────────┘
```

### 模块职责

| 模块 | 职责 |
|------|------|
| **Board State** | 15×15 二维数组（0=空, 1=黑/人, 2=白/AI）；走子历史栈用于悔棋 |
| **Renderer** | Canvas 绘制：棋盘网格、星位点、棋子（径向渐变 3D 效果）、最后一手标记、鼠标悬停预览、五连珠高亮 |
| **Win Detector** | 四方向（横/竖/两条对角线）扫描连续 5 子，返回是否获胜及获胜连线坐标 |
| **AI Engine** | 候选空位筛选 → 逐位模式评分 → 攻防综合排序 → 选最高分位置 |
| **Game Controller** | 回合管理、悔棋（撤回人+AI 两步）、重新开始、状态栏更新 |

## AI 算法

### 候选位筛选

仅评估已有棋子周围 2 格范围内的空位，减少无效计算。空棋盘时默认天元（7,7）。

### 模式评分

对每个候选空位，分别模拟 AI（白）和玩家（黑）落子后的局面，在 4 个方向上统计连续同色棋子数及两端开放情况：

| 模式 | 连续数 | 开放端数 | 得分 |
|------|--------|----------|------|
| 连五 | ≥5 | — | 10,000,000 |
| 活四 | 4 | 2 | 1,000,000 |
| 冲四 | 4 | 1 | 100,000 |
| 活三 | 3 | 2 | 100,000 |
| 眠三 | 3 | 1 | 10,000 |
| 活二 | 2 | 2 | 10,000 |
| 眠二 | 2 | 1 | 1,000 |
| 活一 | 1 | 2 | 1,000 |
| 眠一 | 1 | 1 | 100 |

### 决策优先级

1. AI 能连五 → 直接取胜（优先级 100,000,000）
2. 对手能连五 → 必须堵（优先级 90,000,000）
3. AI 能活四 → 积极进攻（优先级 80,000,000 + 进攻分）
4. 对手能活四 → 优先堵（优先级 70,000,000 + 防守分）
5. 其余 → 进攻分 + 防守分 × 1.1（微偏防守）

同分时随机选择，避免 AI 走子完全确定。

### 视觉规格

- 棋盘底色：木色（#DEB887）
- 网格线：深棕（#8B7355）
- 星位：9 个标准星位点，天元加粗
- 黑子：径向渐变 #666→#222→#000，高光左上
- 白子：径向渐变 #fff→#eee→#ccc，高光左上
- 最后一手：棋子中心标记红点
- 悬停预览：半透明（opacity 0.4）棋子跟随鼠标
- 五连珠高亮：获胜连线上的棋子加金色光晕
- 坐标标注：列 A-O，行 1-15

## 游戏逻辑

### 落子流程

```
玩家点击 → 合法性检查（空位/非终局/人类回合）
         → 更新棋盘 → 渲染
         → 胜负判定 → 胜: 高亮连线，结束
         → 平局判定 → 满盘: 显示平局
         → 切换回合 → 200ms 延迟
         → AI 计算 → 更新棋盘 → 渲染
         → 胜负/平局判定 → 切换回人类回合
```

### 悔棋

撤销最近一对走子（AI 走子 + 人类走子），恢复人类回合。走子历史为空时按钮禁用。

### 重新开始

清空棋盘、走子历史、胜负状态，人类回合。重新渲染。
